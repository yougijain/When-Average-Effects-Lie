When Average Effects Lie

A routine email A/B test, turned into a targeting strategy. The average lift looks healthy — but it hides a 6× difference that flips the right business decision.

Hillstrom experiment · 64,000 customers 3 randomized arms 8-layer pipeline Python · statsmodels · scikit-learn

The decision behind the data

Two promotional emails — one for men's merchandise, one for women's — each lift sales on average. The naive read is "send both to everyone." This analysis shows that read is wrong for one of the two campaigns, and quantifies the better policy.

The headline. The Women's email's +4.5pp average lift is an illusion of aggregation. It moves visits +7.3pp for prior women's-merch buyers but only +1.1pp for those who never bought women's merchandise (and +2.2pp for men's-merch buyers). The Men's email lifts everyone ~7.7pp. Same "positive A/B result"; opposite playbooks.

Qini curve & coefficient (uplift ranking quality)

# sort customers by predicted uplift, accumulate treated vs. control response
def qini_curve(y, treat, score):
    order = np.argsort(-score, kind="mergesort")
    y, t = y[order], treat[order]
    cum_t, cum_c   = np.cumsum(t), np.cumsum(1 - t)
    cum_yt, cum_yc = np.cumsum(y*t), np.cumsum(y*(1 - t))
    ratio = np.where(cum_c > 0, cum_t/cum_c, 0.0)
    qini  = cum_yt - cum_yc*ratio          # control responses re-scaled to treated size
    frac  = np.arange(1, len(y)+1)/len(y)
    total = cum_yt[-1] - cum_yc[-1]*(cum_t[-1]/cum_c[-1])
    qini_coef = TRAPEZOID(qini, frac) - TRAPEZOID(frac*total, frac)
    return frac, qini, frac*total, qini_coef

IPW policy value + cost-sensitive targeting (Layer 7)

# treatment was randomized => propensity p is a known constant => unbiased
p = tte.mean()
def ipw_value(policy):
    w = np.where(policy == 1, (tte == 1)/p, (tte == 0)/(1 - p))
    return (w * yte).mean()      # reduces to mean(treated)/mean(control) at the extremes

breakeven = COST_PER_EMAIL / VALUE_PER_VISIT          # uplift that pays for a contact
pi   = (score > breakeven).astype(int)                # contact only if it pays
nv   = ((ipw_value(pi) - ipw_value(zeros))*VALUE_PER_VISIT
        - pi.mean()*COST_PER_EMAIL) * 1000            # net value / 1,000, incremental only

What the data actually says

All figures are generated by the script. If they don't render, open this file from inside the repo (they live in figures/).

Step 1 — the experiment is trustworthy. Max |standardized mean difference| across covariates = 0.009 (rule of thumb < 0.10), and an omnibus test that covariates jointly predict assignment gives p = 0.76. Randomization holds, so differences are causal.
Step 2 — the average lies. For the Women's email, T×womens-affinity = +6.20pp and T×mens-affinity = −5.22pp (both p < 1e-4, surviving Benjamini-Hochberg FDR). The Men's email shows no such moderation.
